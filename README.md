\# SupplyLink AI



Multi-Warehouse Supply Chain Planner



\## Features

\- Inventory dashboard

\- Low-stock detection

\- Warehouse transfer recommendations

\- Gemini AI assistant

\- CSV reports



\## Technologies

\- Python

\- Streamlit

\- Pandas

\- Matplotlib

\- Google Gemini API



\## Run the project

pip install -r requirements.txt



streamlit run app.py
